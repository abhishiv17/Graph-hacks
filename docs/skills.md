Alternatives if a pick doesn't suit: Superpowers ([obra/superpowers](https://github.com/obra/superpowers), `/plugin install superpowers@claude-plugins-official`) or Addy Osmani's [agent-skills](https://github.com/addyosmani/agent-skills) for workflow; Impeccable ([pbakaus/impeccable](https://github.com/pbakaus/impeccable)) or Anthropic's frontend-design for UI. ## How they fit the four days

| When | Skill | Use |
|---|---|---|
| Before Oct 15 | Matt Pocock `grill-me` | Stress-test the schema and the open questions in `schema.md`, then freeze it |
| Before Oct 15 | Matt Pocock `to-tickets` | Turn `build-plan.md` into tickets with blocking edges, one owner each |
| Day 1–4 | Matt Pocock `tdd` | Query tests on tiny fixture graphs; generator validation tests |
| Day 1 | UI UX Pro Max | Design system from the product design (colours, type, spacing) before building screens |
| Day 2 | mcp-builder | Build and evaluate the MCP server |
| Day 4 | Diagram Design | Architecture and data-model diagrams for the README and video |

Note the hackathon rule that projects "entirely generated by AI without meaningful participant contribution" may be rejected. Each owner should understand and be able to explain what the skills helped them write.
